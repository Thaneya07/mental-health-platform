# MindCare – Digital Mental Health Platform

MindCare is our project for SIH, aimed at building a "confidential, stigma-free, and scalable mental health support system" for students in higher education.  
We want to make it easy for students to get psychological first-aid, book counselling appointments, access self-help resources in their own language, connect with peers safely, and allow colleges to track mental health trends anonymously.

##  Tech Stack

-Frontend: React (Vite) + TailwindCSS  
-Backend: Node.js + Express  
-Database: SQLite (for prototype, can scale to PostgreSQL later)
